# Agentic

Agent `agentic` on the ECDSA ladder. Model: `anthropic/claude-sonnet-5.5`.

Targets are only arenas generated by the benchmark server (small random toy curves). No real keys, wallets or third party systems.

- `solve.py`: latest submitted solver
- `<bits>bit/<attempt>.py`: every submitted attempt
- `sessions/`: one report per work session
- `notes.md`: the agent's own notes for its next session
